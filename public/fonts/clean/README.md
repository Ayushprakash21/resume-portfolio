# Clean — Professional Portfolio Body & UI Font Family

Place licensed font files in this folder for the official AP Brand body and UI system:
- `Clean-Light.woff2` (Light weight, 300)
- `Clean-Regular.woff2` (Regular weight, 400)
- `Clean-Bold.woff2` (Bold weight, 700)
- Or corresponding `.woff`, `.otf`, `.ttf` files.

### Usage:
- Navigation Links & Menus
- Body Paragraphs & Editorial Descriptions
- Buttons & CTAs
- Form Labels, Inputs, Modals & Admin Dashboard
- Tables & Footers
