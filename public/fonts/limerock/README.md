# Limerock — Proprietary Display Typeface Slot (Optional Local WOFF2 Drop-In)

**License Notice:**  
Limerock (created by Lewis Read / East Coast Font Club) is a commercial typeface. Public demo downloads on font aggregator websites are strictly licensed for **personal desktop use only** and do **not** permit self-hosted webfont (`@font-face` WOFF2) distribution without a purchased commercial webfont license.

Because no licensed Limerock WOFF2 files exist in this repository, the website uses **Plus Jakarta Sans** (SIL Open Font License 1.1, self-hosted via `@fontsource/plus-jakarta-sans`) as its honest, legally licensed default display heading font.

### To Activate Authentic Licensed Limerock Webfont Later:
1. Purchase the official webfont license for Limerock from East Coast Font Club / an authorized distributor.
2. Place the licensed webfont files in this folder (`public/fonts/limerock/`):
   - `Limerock-Regular.woff2` (400)
   - `Limerock-Medium.woff2` (500)
   - `Limerock-SemiBold.woff2` (600)
   - `Limerock-Bold.woff2` (700)
3. Open **Admin -> Settings -> Typography & Appearance**, select **Limerock** as the Heading Font, verify the font loading indicator shows `Loaded`, preview across viewports, and click **Publish Changes**.
