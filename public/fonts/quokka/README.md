# Quokka — Modern Resume & Editorial Accent Font

Place licensed font files in this folder for the official AP Brand editorial accent typography:
- `Quokka.woff2` (Regular style)
- `Quokka-Italic.woff2` (Italic style)
- Or corresponding `.woff`, `.otf`, `.ttf` files.

### Usage:
- Hero Subtitles (`Intelligence & Innovation.`)
- Italic Editorial Accents & Subheadings
- Selected Quotations & Project Subtitles
- Featured Highlights & Callout Phrases
