# Orenza Bold — Modern Display & Brand Font

Place licensed font files in this folder for the official AP Brand display hierarchy:
- `Orenza-Bold.woff2` (Recommended for web delivery)
- `Orenza-Bold.woff`
- `Orenza-Bold.otf`
- `Orenza-Bold.ttf`

### Usage:
- Homepage Hero Headline (`BUSINESS. SYSTEMS.`)
- Brand Header (`AYUSH PRAKASH`)
- Major Section Headings (`#projects`, `#experience`, `#about`, `#opentowork`)
- Featured Project Names
- Modal & Dashboard Primary Titles
